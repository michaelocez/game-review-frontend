# Game Review Website Frontend – University of Canterbury

React frontend for the Game Review Website course project.
This version demonstrates the user interface, styling, and component structure.

## Features
- Fully built with React
- Component-based architecture
- Responsive design with CSS
- Demonstrates layout, styling, and UI functionality

## Running Locally
To view the project locally:

1. Clone the repository:
   ```git clone https://github.com/michaelocez/game-review-frontend.git```

2. Install dependencies:
    ```npm install```

3. Start the development server:
    ```npm start```

4. Open in your browser:
    http://localhost:3000
